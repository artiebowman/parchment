# Parchment — HCC 552 HW1

3D sphere selection task, Meta Quest 3S, hands only.
Technique: **Parchment** — the 100-sphere cube is projected once, during untimed setup,
onto a 2D parchment of bulbs; every selection is a hover and a pinch.

- `docs/PLAN.md` — phases with exit tests, questions for Khan
- `docs/DECISIONS.md` — every design decision and the rejected ideas
- `docs/SETUP.md` — Phase 0 environment setup, both machines
- `Data/` — the supplied `sphere_coordinates.txt` and `test_sequences.txt`
  (copy into `Assets/StreamingAssets/` once the Unity project exists)

Unity 6000.6.0f1 · Meta XR Core SDK · Meta XR Interaction SDK · OpenXR
